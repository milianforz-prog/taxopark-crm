# Бот для водителей — @Alitsksismena1_bot

Работает в Supabase (функция `driver-bot`, webhook Telegram), компьютер не нужен.

## Для водителя
1. `/start` → кнопка «📱 Отправить номер телефона» (принимается только свой контакт).
2. Номер сверяется с водителями парка (последние 10 цифр, уволенные не входят).
3. Личный кабинет: ФИО, парк, баланс (свежий из Яндекса), авто, статус, смена.
4. **Купить смену** — подтверждение → с баланса в Яндекс Про списывается цена смены
   (транзакция `partner_service_manual`, «Покупка смены (бот)»). Если денег на балансе не хватает — отказ.
5. **Отключить смену** — только через 6 дней после покупки. Раньше бот покажет дату, с которой можно.

## Для сотрудника (CRM → карточка водителя → блок «Смена»)
- **Цена смены** — у каждого водителя своя. Пока цена не задана, купить смену нельзя.
- Видно, активна ли смена, когда куплена и с какого момента водитель может её отключить.
- **Завершить смену** — досрочно, деньги не возвращаются автоматически.

## Устройство
- Таблицы: `shift_prices` (цены), `shifts` (смены: pending → active → ended / failed), `driver_telegram` (входы).
- Токен бота и секрет webhook — в `private.settings` (`driver_bot_token`, `driver_bot_webhook_secret`).
- Сменить токен: обновить `driver_bot_token` и заново вызвать `setWebhook` на
  `https://ovgiuxulyrxiljfqpaml.supabase.co/functions/v1/driver-bot` с `secret_token`.
- Если списание упало с ошибкой — смена получает статус `failed` с текстом ошибки, деньги не списаны.
