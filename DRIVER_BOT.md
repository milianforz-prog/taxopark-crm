# Бот для водителей

Отдельный Telegram-бот (`driver_bot.py`): водитель входит по номеру телефона, попадает в личный
кабинет и сам покупает / отключает смену.

## Как работает

1. `/start` → бот просит нажать «📱 Отправить номер телефона» (принимается только **свой** контакт).
2. Номер сверяется с водителями всех парков из `parks.json` (по последним 10 цифрам, уволенные не входят).
   Если номер есть в нескольких парках — водитель выбирает профиль.
3. Личный кабинет: ФИО, парк, баланс, авто, статус, текущее условие работы, состояние смены.
4. **Купить смену** → список смен парка → подтверждение → водитель переводится на условие работы
   смены через Fleet API (`PUT /v2/parks/contractors/driver-profile`, меняется `account.work_rule_id`).
   Оплату за смену списывает сам Яндекс по настройкам условия работы.
5. **Отключить смену** — только через 6 дней после подключения (раньше бот покажет дату, с которой можно).
   Водитель возвращается на условие, на котором был до покупки (или на `default_rule_id`).
6. О покупке и отключении приходит уведомление сотрудникам в основной бот (`TELEGRAM_CHAT_ID`).

## Настройка

1. Создайте нового бота у @BotFather и добавьте в `.env`:
   ```
   DRIVER_BOT_TOKEN=123456:ABC...
   SHIFT_MIN_DAYS=6
   ```
2. В кабинете Яндекс Про у API-ключа должен быть доступ к условиям работы и профилям водителей (запись).
3. Смены — это условия работы со словом «смена» в названии. Можно задать явно в `parks.json`:
   ```json
   [{"name": "Парк", "park_id": "...", "api_key": "...",
     "shift_rules": ["id_условия_смена_1", "id_условия_смена_2"],
     "default_rule_id": "id_обычного_условия"}]
   ```
4. Запуск: `python driver_bot.py` (держать запущенным, как `bot.py`).

Состояние (кто вошёл, когда подключена смена) хранится в `driver_bot_state.json` — не удаляйте его,
иначе отсчёт 6 дней начнётся заново. Если смену поставил диспетчер вручную, бот начинает отсчёт
с момента, когда впервые её увидел.
